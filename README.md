# Oceanic – Marine Life & Ocean Exploration

Oceanic is a responsive marine exploration website created to showcase the beauty and diversity of the world's oceans. The website presents marine species, ocean zones, deep-sea exploration, conservation topics, interesting facts, and underwater photography through a modern ocean-themed interface.

## Features

* Responsive navigation bar
* Full-screen ocean hero section
* Ocean statistics section
* Marine life showcase
* Detailed marine animal cards
* Ocean zones information
* Deep-sea exploration section
* Ocean conservation section
* Interesting ocean facts
* Underwater image gallery
* Responsive design for different screen sizes
* Interactive hover effects
* Modern card-based layout
* Call-to-action section

## Technologies Used

* HTML5
* Tailwind CSS
* Responsive Web Design
* Unsplash Images

## Website Sections

### Hero

Introduces Oceanic with an immersive underwater background and calls users to explore marine life.

### About the Ocean

Provides information about the importance of oceans and their role in Earth's ecosystem.

### Marine Life

Showcases different marine animals and organisms with images and short descriptions.

### Ocean Zones

Explains the major ocean zones, including the Sunlight, Twilight, Midnight, Abyssal, and Hadal zones.

### Deep Sea Exploration

Highlights underwater research, ocean mapping, submersibles, and deep-sea discoveries.

### Conservation

Covers important environmental topics such as plastic pollution, overfishing, coral reef protection, and climate action.

### Ocean Facts

Presents interesting facts about marine environments and ocean ecosystems.

### Gallery

Displays a collection of underwater and ocean-themed images.

## Design

The website uses a dark ocean-inspired interface with navy, cyan, and aqua shades. Large imagery, rounded cards, structured layouts, and responsive sections create an immersive browsing experience.
